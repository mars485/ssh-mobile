# Политика конфиденциальности / Privacy Policy

**Приложение:** SSH Mobile (`dev.sshmobile`)  
**Дата вступления в силу:** 29 октября 2026 г.  
**Разработчик:** SSH Mobile (open-source проект, GitHub: [mars485/ssh-mobile](https://github.com/mars485/ssh-mobile))

## Кратко

SSH Mobile не собирает, не передаёт и не продаёт персональные данные. Приложение работает
локально на устройстве и подключается только к тем SSH-серверам, которые пользователь
добавил сам.

## 1. Какие данные обрабатываются

Приложение хранит **только на устройстве**:

- имя, адрес, порт и имя пользователя SSH-сервера;
- группу и признак «избранное»;
- зашифрованные пароли, приватные ключи и парольные фразы;
- отпечатки доверенных host key;
- настройки интерфейса (язык, тема, размер шрифта и т.п.).

Пароли и ключи шифруются ключом Android Keystore (AES-256-GCM); ключ не экспортируется
и не передаётся разработчику.

## 2. Передача данных

- Приложение не содержит аналитики, рекламы, crash-репортинга и трекеров.
- Сетевые соединения устанавливаются **только** к серверам, которые пользователь указал
  в приложении, по протоколу SSH.
- Разработчик не получает доступ к серверам, учётным данным, содержимому терминала или
  статистике использования.
- Приложение не передаёт данные третьим лицам.

## 3. Разрешения

- `INTERNET` — SSH-подключения к серверам пользователя.
- `ACCESS_NETWORK_STATE` — проверка доступности сети.
- `VIBRATE` — необязательная обратная связь интерфейса.

Доступ к файлам используется только через системный выбор файла (SAF) при импорте
приватного ключа; приложение не сканирует хранилище.

## 4. Буфер обмена и скриншоты

- Копирование текста помещает его в системный буфер обмена, доступный другим приложениям.
- Вставка выполняется только по явному действию пользователя.
- Режим «Блокировать скриншоты» включает `FLAG_SECURE`; по умолчанию выключен.
- Приложение не читает буфер обмена автоматически.

## 5. Резервное копирование

Резервное копирование данных приложения отключено (`android:allowBackup="false"`).
Данные не выгружаются в облако средствами приложения. Пользователь может удалить все
данные через «Настройки → Стереть все данные приложения».

## 6. Хранение и удаление

Данные хранятся на устройстве до удаления приложения или очистки данных. Удаление
приложения удаляет базу данных и ключ Android Keystore. Серверы и отпечатки host key
можно удалить отдельно в настройках.

## 7. Дети

Приложение не предназначено специально для детей и не собирает данные о них.

## 8. Изменения политики

Актуальная версия публикуется в этом файле в репозитории. Существенные изменения
отражаются в `CHANGELOG.md`.

## 9. Контакты

Вопросы и сообщения об уязвимостях: [GitHub Issues](https://github.com/mars485/ssh-mobile/issues).
Не прикладывайте реальные пароли и приватные ключи.

---

## English summary

SSH Mobile does not collect, transmit, or sell personal data. Server credentials are stored
locally and encrypted with an Android Keystore key. Network connections are made only to
servers explicitly added by the user. There are no analytics, ads, or crash reporting.
Backups are disabled. Clipboard access happens only on explicit user action. The app is
open source at https://github.com/mars485/ssh-mobile.
