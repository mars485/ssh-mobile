## Полное описание

```text
SSH Mobile — нативный SSH-клиент для Android с полноценным интерактивным терминалом.

Возможности:
• менеджер серверов: группы, избранное, поиск, быстрый запуск;
• вход по паролю или приватному ключу (PEM/OpenSSH, passphrase);
• терминал VT100/xterm: bash, zsh, htop, vim, nano, less;
• экранные клавиши Ctrl/Alt/Esc/Tab, стрелки, копирование и вставка;
• несколько одновременных сессий, переподключение после обрыва;
• проверка host key с SHA-256 fingerprint и предупреждением при смене ключа;
• шифрование паролей и ключей через Android Keystore;
• русский и английский интерфейс, тёмная тема.

Приложение не содержит рекламы, аналитики и трекеров. Данные хранятся только на
устройстве. Для работы нужен собственный SSH-сервер — демо-аккаунта нет.

Ограничения MVP: SFTP, jump host и port forwarding появятся в следующих версиях.

Приложение с открытым исходным кодом: https://github.com/mars485/ssh-mobile
```

## Комментарий для модератора

Примечание: API RuStore ограничивает это поле 180 символами. Длинный текст ниже — для
веб-консоли; короткая версия для скрипта лежит в `store/rustore.json` (`moderInfo`).

```text
Приложение не содержит рекламы, аналитики, встроенных покупок и пользовательского
контента. Все данные (серверы, ключи, отпечатки host key) хранятся только на
устройстве; пароли и приватные ключи шифруются ключом Android Keystore.

Сетевые соединения выполняются только к SSH-серверам, которые пользователь добавил
сам. Публичного демо-сервера нет по соображениям безопасности — инструкция по
локальному тестовому серверу: https://github.com/mars485/ssh-mobile/blob/main/docs/TESTING.md

Сценарий проверки: установить APK → «Добавить сервер» (имя, host, порт,
пользователь, пароль или ключ) → подключиться → сверить и принять SHA-256
fingerprint host key → выполнить echo hello / htop / vim → открыть «Сессии» и
закрыть сессию → сменить язык в настройках (Системный / English / Русский).

Исходный код: https://github.com/mars485/ssh-mobile
Политика конфиденциальности: https://github.com/mars485/ssh-mobile/blob/main/docs/PRIVACY.md
```
