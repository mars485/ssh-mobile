# Changelog

## 0.3.0 — 08.11.2026

### v0.2 — расширенный терминал

- Локальные сниппеты и панель истории команд в терминале. История выключена по умолчанию;
  история и сниппеты хранятся зашифрованными через Android Keystore. История не перехватывает
  стрелки ↑/↓ и не записывает ввод в альтернативном экране/TUI.
- Выбор системного моноширинного шрифта, размера шрифта и четырёх цветовых схем терминала;
  настройки сохраняются на устройстве и применяются сразу.
- SSH jump host (ProxyJump) через сохранённый сервер-шлюз. Проверяются оба host key —
  и шлюза, и целевого сервера; вложенные jump host не поддерживаются.
- Локальный и удалённый port forwarding. По умолчанию проброс слушает `127.0.0.1`;
  пробросы закрываются вместе с SSH-сессией.
- Экспорт и импорт конфигурации без секретов: пароли, приватные ключи и passphrase
  не выгружаются, jump host ссылается по имени. Импортированный сервер можно сохранить
  без учётных данных и заполнить их позже.
- Room-миграция 1→2 (`jumpServerId`), существующие серверы не теряются.

### v0.3 — SFTP

- Полноценный файловый менеджер: просмотр каталогов, переход вверх, обновление,
  создание папок, переименование, удаление (включая рекурсивное), изменение прав
  восьмеричным режимом.
- Загрузка и скачивание файлов через SAF с прогрессом и очередью передач.
- SFTP использует те же шифрованные учётные данные и строгую проверку host key, что
  и терминал; при новом хосте запрашивается подтверждение fingerprint.
- Передачи открывают отдельный SFTP-канал, поэтому просмотр каталога не блокируется
  во время загрузки/скачивания. Активные передачи останавливаются при отключении.
- Одновременно подключён один SFTP-сервер; каталоговые операции сериализованы.

## 0.1.2 — 29.10.2026

- Исправлено падение при открытии экрана добавления сервера после локализации:
  `ActivityResultRegistryOwner` теперь явно передаётся в Compose-дерево, поэтому
  `rememberLauncherForActivityResult` (импорт SSH-ключа через SAF) работает.
- Проверено на HONOR Android 14: экран «Новый сервер» открывается, форма прокручивается
  при открытой клавиатуре.
- Сборка: versionCode 3, versionName 0.1.2.

## 0.1.1 — 29.10.2026

- Русская локализация интерфейса и выбор языка: «Системный», English, Русский.
- Мгновенное переключение языка без перезапуска; выбор сохраняется в DataStore.
- Все строки, ошибки, диалоги host key и валидация формы вынесены в ресурсы
  (`values`, `values-ru`).
- Исправлено перекрытие полей формы экранной клавиатурой: `imePadding` и прокрутка
  контента.
- Добавлены материалы для RuStore, политика конфиденциальности и лицензии.
- Сборка: versionCode 2, versionName 0.1.1.

## 0.1.0 — 29.10.2026

- Первый MVP: менеджер серверов, пароль и SSH-ключ, PTY-терминал, host-key verification,
